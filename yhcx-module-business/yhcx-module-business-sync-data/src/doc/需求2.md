## 查询数据库表dataset_record_info

背景：将dataset_record_info表对应到ds_dataset新表。每一条数据复制成一个新的ds_dataset。本此需求是两MinIO复制文件。

注：此模块被ds_dataset模块调用，因此ds_dataset数据的查询和新增在ds_dataset模块中，不在此模块处理。

1. 查询数据表 dataset_record_info，拿到批量MinIO文件路径（dataset_storage_path字段）
2. 使用S3Client读取每个dataset_record_info.dataset_storage_path路径下的所有文件
3. 将读取到的文件上传到另一MinIO中，使用com.yhcx.framework.file.core.service.S3FileStorageService.putObject
```java
Object putObject(String bucketName, String rootPath, String path, Map<String, String> metadata);
```
  - bucketName 固定值
  - rootPath 固定值
  - path ds_dataset表中的根路径
  - metadata 固定设置{"dataset":"ds_dataset表主键ID"}
